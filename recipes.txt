## Fonts

explore https://github.com/ryanoasis/nerd-fonts

wget -P ~/.local/share/fonts https://github.com/ryanoasis/nerd-fonts/releases/download/v3.0.2/JetBrainsMono.zip \
&& cd ~/.local/share/fonts \
&& unzip JetBrainsMono.zip \
&& rm JetBrainsMono.zip \
&& fc-cache -fv

## OTF fonts

move font to /usr/share/fonts/opentype 
fc-cache -f -v

## command not found

1. find package name in https://command-not-found.com/
2. download for your distro and arch: https://packages.debian.org/bookworm/amd64/calcurse/download
3. sudo dpkg -i <package name>
4. sudo dpkg-query -L calcurse
