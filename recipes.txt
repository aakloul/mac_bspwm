# Install Snap software

https://snapcraft.io/docs/get-started

1. install snap

  sudo apt update
  sudo apt install snapd

2. enable snapd and apparmor services

	sudo systemctl enable --now snapd apparmor
	#sudo systemctl start snapd.apparmor


3. install the latest snapd

	sudo snap install snapd

4. install your software

	sudo snap install hello-world
	sudo snap install arduino
	sudo snap install betaflight-configurator

5. find, list and run your software

	snap find "media player"
	snap list
	snap run hello-world
